# MultiMedia Converter

صفحة ويب لتحويل الصور والصوت والفيديو داخل المتصفح، مع حفظ الملفات وبياناتها في Supabase وعرضها وتنزيلها وحذفها.

## محتويات المشروع

```
MultiMedia-Converter/
├── index.html               ← الصفحة الرئيسية (مقفلة لغير المسجّلين)
├── login.html               ← تسجيل الدخول
├── signup.html              ← إنشاء حساب
├── forgot-password.html     ← طلب رابط استعادة كلمة المرور
├── reset-password.html      ← تعيين كلمة مرور جديدة من رابط البريد
├── css/style.css            ← التصميم (وردي وبنفسجي)
├── js/config.js             ← ضع مفاتيح Supabase هنا
├── js/supabase-client.js    ← عميل Supabase المشترك
├── js/auth-guard.js         ← قفل الصفحة الرئيسية
├── js/auth.js               ← منطق صفحات الدخول والتسجيل والاستعادة
├── js/encoders.js           ← ترميز WAV و BMP
├── js/app.js                ← التحويل والحفظ والمكتبة
├── supabase/setup.sql       ← إنشاء الجدول والتخزين
└── supabase/auth-setup.sql  ← خصوصية الملفات لكل مستخدم
```

## التحويلات المتاحة

| النوع | من | إلى | الخيارات |
|---|---|---|---|
| صور | PNG, JPG, WEBP, GIF, BMP, SVG | PNG, JPG, WEBP, BMP | الجودة، تصغير العرض، أبيض وأسود |
| صوت | MP3, WAV, OGG, M4A, FLAC, WEBM | WAV, WebM/Opus | معدل العيّنات، مونو/ستيريو، معدل البت |
| فيديو | MP4, WEBM, MOV | WebM، صوت WAV، لقطة PNG/JPG | الدقة، الجودة، وقت اللقطة |

كل التحويل يتم على جهازك داخل المتصفح باستخدام Canvas وWeb Audio API وMediaRecorder، دون خادم.

## التشغيل على ويندوز خطوة بخطوة

### أولًا: تجهيز البرامج
1. ثبّت متصفح **Google Chrome** أو **Microsoft Edge** (Edge موجود في ويندوز أصلًا).
2. نزّل **Visual Studio Code** من code.visualstudio.com وثبّته.
3. افتح VS Code، اضغط أيقونة المربعات على اليسار (Extensions)، ابحث عن **Live Server** وثبّته.

### ثانيًا: إعداد Supabase
1. ادخل supabase.com وسجّل حسابًا مجانيًا.
2. اضغط **New project**، اختر اسمًا وكلمة مرور وأقرب منطقة، وانتظر حتى يجهز (دقيقتان تقريبًا).
3. من القائمة الجانبية اختر **SQL Editor** ثم **New query**.
4. افتح ملف `supabase/setup.sql` من المشروع، انسخ كل محتواه، الصقه، ثم اضغط **Run**. يجب أن تظهر رسالة Success.
5. اذهب إلى **Project Settings ← API** (قد تسمى Data API أو API Keys).
6. انسخ **Project URL** ومفتاح **anon public** (أو **Publishable key**).

### ثالثًا: ربط المشروع
1. فك ضغط ملف المشروع في مكان سهل، مثل سطح المكتب.
2. في VS Code اختر **File ← Open Folder** وافتح مجلد `MultiMedia-Converter`.
3. افتح `js/config.js` وضع القيمتين بين علامتي التنصيص:
   ```js
   SUPABASE_URL: "https://abcd1234.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```
4. احفظ بـ `Ctrl + S`.

### رابعًا: التشغيل
1. انقر بالزر الأيمن على `index.html` واختر **Open with Live Server**.
2. ستفتح الصفحة على عنوان مثل `http://127.0.0.1:5500`.
3. أعلى الصفحة يجب أن يظهر «متصل بـ Supabase» بنقطة خضراء.

**بديل بدون VS Code:** إذا كان Python مثبتًا، افتح مجلد المشروع، اكتب `cmd` في شريط العنوان واضغط Enter، ثم نفّذ:
```
python -m http.server 8000
```
وافتح `http://localhost:8000` في المتصفح.

### خامسًا: التجربة
1. اختر تبويب صور أو صوت أو فيديو، واسحب ملفًا إلى المربع.
2. اختر الصيغة والإعدادات ثم اضغط **حوّل الملف**.
3. اضغط **تنزيل** لحفظه على جهازك، أو **حفظ في Supabase**.
4. انزل إلى «الملفات المحفوظة» للعرض والتنزيل والحذف.
5. للتأكد: في Supabase افتح **Table Editor ← media_files** و **Storage ← media**.

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «غير متصل: أضف مفاتيح Supabase» | لم تعدّل `js/config.js` أو لم تحفظه |
| «خطأ في الجدول: شغّل ملف setup.sql» | شغّل `setup.sql` في SQL Editor مرة أخرى |
| فشل الحفظ: new row violates row-level security | أعد تشغيل `setup.sql` كاملًا |
| فشل الحفظ: Payload too large | الملف أكبر من 50MB، اختر جودة أو دقة أقل |
| تحويل الفيديو بطيء | طبيعي، فهو يتم بسرعة التشغيل. أبقِ الصفحة ظاهرة |
| ملف MOV أو MKV لا يعمل | صيغته غير مدعومة في المتصفح، جرّب MP4 |

اضغط `F12` ثم تبويب **Console** لرؤية تفاصيل أي خطأ.

## نظام الحسابات

### إعداد المصادقة في Supabase
1. في **SQL Editor** شغّل `supabase/setup.sql` ثم `supabase/auth-setup.sql` بالترتيب.
2. افتح **Authentication ← URL Configuration**:
   - **Site URL:** رابط موقعك، مثل `https://اسمك.github.io/multimedia-converter/`
   - **Redirect URLs:** أضف الرابطين التاليين:
     - `https://اسمك.github.io/multimedia-converter/**`
     - `http://127.0.0.1:5500/**` (للتجربة المحلية بـ Live Server)
3. احفظ.

بدون الخطوة 2 ستفتح روابط التأكيد والاستعادة على صفحة خاطئة.

### تأكيد البريد
Supabase يرسل رسالة تأكيد بعد التسجيل افتراضيًا. البريد المجاني المدمج محدود بعدد قليل من الرسائل في الساعة، فإذا لم تصل الرسالة انتظر قليلًا.
للتجربة السريعة يمكنك إيقاف التأكيد من **Authentication ← Sign In / Providers ← Email ← Confirm email**، فيدخل المستخدم مباشرة بعد التسجيل.

### كيف تعمل الحماية
- `auth-guard.js` يُخفي الصفحة الرئيسية ويحوّل أي زائر غير مسجّل إلى `login.html`.
- الحماية الحقيقية للبيانات في قاعدة البيانات نفسها: سياسات `auth-setup.sql` تمنع أي شخص من قراءة أو حذف ملفات غيره، حتى لو حاول الاتصال بـ Supabase مباشرة.
- حاوية التخزين أصبحت خاصة، والمعاينات تُعرض بروابط موقّعة صالحة لساعة.
- كل مستخدم يرى مكتبته فقط.

### مشكلات شائعة في الحسابات
| المشكلة | الحل |
|---|---|
| رابط البريد يفتح localhost:3000 | اضبط Site URL و Redirect URLs |
| «انتهت صلاحية الرابط» | الرابط يُستخدم مرة واحدة، اطلب رابطًا جديدًا |
| «لم تؤكد بريدك» | افتح رسالة التأكيد، أو اضغط «أعد إرسال رسالة التأكيد» |
| الملفات القديمة اختفت | حُفظت قبل الحسابات وليس لها صاحب |
| فشل الحفظ: row-level security | شغّل `auth-setup.sql` مرة أخرى |

## ملاحظة أمان
لا تضع مفتاح `service_role` في الكود أبدًا. مفتاح `anon` آمن للنشر لأن سياسات RLS تحمي البيانات.
